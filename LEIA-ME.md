# Como começar

1. Crie uma pasta para o projeto e coloque nela: `PROMPT.md`, `temas_iniciais.csv` e a pasta `referencia/`.
2. Abra a pasta no VS Code e, na extensão do Claude Code, peça:
   "Leia o PROMPT.md e comece pela fase 1."
3. Os ganchos em `temas_iniciais.csv` são ideias de abertura: os números neles ainda precisam
   ser checados pelo roteiro com fonte, como manda o PROMPT.md.
